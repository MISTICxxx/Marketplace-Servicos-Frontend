# Wireframes iniciais

`index.html` reúne cinco wireframes esquemáticos de baixa fidelidade: página inicial, diretório, perfil de prestador, criação de solicitação e conversa com apresentação de proposta.

Abra `index.html` diretamente em um navegador. O arquivo usa apenas HTML e CSS locais e se reorganiza para telas menores; não requer servidor, pacote ou acesso à internet. Os textos e cartões são esquemáticos e não representam dados ou profissionais reais.

Estes arquivos são wireframes locais, não um protótipo compartilhado do Figma. A transposição para Figma e o compartilhamento de um link continuam pendentes.
